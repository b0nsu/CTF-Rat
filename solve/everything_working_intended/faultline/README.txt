FAULTLINE

Requirements:
  - Linux x86-64
  - qemu-system-x86_64 7.2 or newer
  - 1 GiB free RAM

Run the challenge:
  ./run.sh

Run the public calibration profile:
  ./run.sh calibration

The calibration profile does not emit a trace. The separately supplied
factory_calibration.trace was captured from a correctly calibrated unit.
