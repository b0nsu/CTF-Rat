# Dog Simulator

## Summary
The challenge provides only a macOS arm64 Mach-O. I parsed the Mach-O enough to locate `__text`, `__cstring`, and `__DATA_CONST`, disassembled `main` with Capstone, then emulated it with Unicorn.

## Solution
The game is a six-day state machine. The finale checks action counts, score, energy, combo state, a rolling action hash, and a rolling command hash.

The `Speak` command hash is FNV-like over lowercase alphabetic characters. A short target preimage was found first:

```text
rjeeqwm -> 0x9f58d866
```

The final check also requires total speak letters to be 19 and a second rolling hash to match. A 12-letter preimage was generated by randomized meet-in-the-middle:

```text
knqrgrylbmak -> 0x9f58d866
```

The winning sequence is:

```text
2
3
1
6
knqrgrylbmak
4
6
gremlin
```
